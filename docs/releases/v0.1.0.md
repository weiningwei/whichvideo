# WhichVideo v0.1.0

首个跨平台公开预览版，面向 Windows x64、macOS Apple Silicon / Intel 和 Linux x64。WhichVideo 在本机为视频抽帧建立指纹索引，可用截图查找视频及画面时间点，也能查找库内相似视频。

## 主要功能

- 导入单个或多个视频、一次性导入文件夹，或选择持续监视文件夹；文件夹视图可逐层展开。
- 拖入图片、选择图片、粘贴截图或输入网页链接进行以图搜帧；结果显示文件名、所在目录、相似度和命中时间。
- 查重结果按相似组呈现，同名文件显示各自目录；移除只影响索引库，不删除磁盘文件。
- 支持均匀采样和场景检测采样，以及单视频或批量重建索引。
- 安装版和便携版都把索引与日志保存在程序同级的 `data` 目录；macOS WebView 界面偏好由系统管理。

## 本版修复与调整

- 从 Electron 迁移至 Tauri/Rust，并重新整理视频库的文件夹视图、选择与更多操作。
- 修复便携版导入、索引和重建索引过程中的稳定性问题。
- 查重和搜图结果补充目录信息；查重移除失败时保留未成功处理的结果。
- 新搜索或清除后不再被旧请求覆盖；预览读取失败会回退或提示，不会一直显示加载中。
- 修复场景检测取消与无切换点时的抽帧路径；搜索精修复用已解码的命中帧，索引时尽量复用邻近帧生成缩略图，重复导入未变化的视频不再重算文件哈希。

## 下载与使用

- `WhichVideo-0.1.0-windows-x64-setup.exe`：Windows 安装版。
- `WhichVideo-0.1.0-windows-x64-portable.zip`：免安装版；解压后运行 `WhichVideo.exe`，升级时保留整个 `data` 目录。
- `WhichVideo-0.1.0-macos-arm64-portable.zip`：解压 `.app` 到可写目录后启动；数据保存在 `.app` 同级的 `data`，不要放到无写权限的 `/Applications`。
- `WhichVideo-0.1.0-macos-x64-portable.zip`：Intel Mac 的同款便携版，使用方式相同。
- `WhichVideo-0.1.0-linux-x64.AppImage`：赋予执行权限后从可写目录启动；数据保存在 AppImage 同级的 `data`。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

所有版本均**不内置 FFmpeg**。首次启动如未检测到 `ffmpeg` 和 `ffprobe`（Windows 为 `.exe`），请在提示或「索引设置 → 媒体工具」中指定包含两者的 `bin` 目录。程序目录必须可写。

当前尚未配置 Windows 代码签名或 Apple 签名/公证，系统可能拦截下载的程序。发布前必须在三个系统上分别检查首次启动、导入、索引、截图粘贴、网页取图、搜索、查重和数据保留；未验收的平台不得标为稳定支持。
