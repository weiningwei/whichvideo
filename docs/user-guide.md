# 使用指南

安装步骤见 [README](../README.md#下载与安装)，启动和工具问题见 [排障手册](troubleshooting.md)。

## 导入与目录管理

| 入口 | 行为 |
| --- | --- |
| 添加 → 视频文件 | 导入选中的文件，不监视所在目录 |
| 添加 → 导入文件夹 | 递归扫描一次，保留目录层级 |
| 添加 → 监视文件夹 | 首次扫描，并持续同步新增、修改和删除 |
| 拖入视频库 | 导入文件或扫描文件夹一次 |
| 拖入「管理文件夹」抽屉 | 添加持续监视 |

默认文件夹视图可逐层展开，也可切换「全部视频」。使用关键字与状态筛选、排序和行选择管理视频；
`Shift` 连选、`Ctrl` 点选，按 `?` 查看完整快捷键。输入框聚焦时，列表快捷键让位给文字输入。

在「管理文件夹」中可暂停、恢复监听或重新扫描。暂停只停止监视，保留已入库记录。
从库中移除目录会清理其未被其他导入目录覆盖的视频索引；另行导入的视频不受影响。
**所有“从库中移除”操作都不删除原视频。**

支持 MP4、MKV、AVI、MOV、WebM、TS 等 FFmpeg 可解码格式；未知扩展名也会尝试验证。
文件须有可读取的视频画面和确定时长。扫描会跳过明显无关的文件，验证失败会给出原因。

本地 `.m3u8` 点播列表可以入库，引用的片段和子列表不会重复入库。
不支持远程片段或无确定时长的实时流；只修改列表引用的片段后，需要手动重建该视频索引。

## 搜图与结果核对

在搜图页选择或拖入图片、粘贴截图，或输入网页链接后回车搜索。
网页链接仅在提交时请求，支持 HTTP/HTTPS 图片直链及包含图片的网页；
网页优先取 `og:image`、`twitter:image` 等预览图，找不到时尝试首张图片。
下载图片上限 10 MB，超时 15 秒；无法取图时可自行保存图片后搜索。

结果显示视频文件名、所在目录、相似度、命中时间和缩略图。
同名视频先核对目录；相似度是算法分数，不代表匹配正确概率。

- **播放**：使用可用播放器打开文件；只有支持时间定位的播放器才能跳到命中位置。
- **定位**：在系统文件管理器中定位原文件。
- **重新索引**：视频发生变化或需要调整采样方式时重新抽帧。

未命中不代表视频一定不在库中。先确认索引完成，再检查截图是否有裁剪、遮挡或强滤镜。
短镜头可能没有被采到；可尝试场景模式重建，并使用视频中较完整的一帧查询。
命中时间来自采样和邻域精修，不保证逐帧准确。

## 查找重复视频

在视频库「更多」菜单选择「查找重复视频」。结果按相似组显示，可调整保留项后批量从库中移除。

- **完全相同文件**：通过文件 SHA-256 校验确认。
- **相似视频**：根据多个时间点的画面和覆盖率判断，可能包含不同编码或剪辑版本。

片头、回顾等重复镜头仍可能造成误判。处理前核对目录、时长、体积并播放确认。
移除仅影响索引库；关闭查重窗口后，下次会重新计算结果。

## 采样与设置

在「索引设置」调整默认值；视频行的更多菜单可单独选择采样方式并重建。

| 设置 | 默认 | 用途 |
| --- | --- | --- |
| 采样模式 | 均匀 | 按间隔取帧；场景模式优先取切换点并补充镜头内部帧，通常更慢 |
| 均匀采样间隔 | 15 秒 | 每个间隔取一帧；视频越长，帧数随时长增长 |
| 场景采样帧数上限 | 240 | 仅约束场景检测模式的代表帧数量 |
| 并发解码数 | 2 | 多任务同时处理；磁盘或 CPU 饱和时应降低 |
| 匹配阈值 | 60% | 结构相似度筛选值，调低会放入更多弱候选，仍受内部剪枝限制 |
| 最多返回结果 | 40 | 限制结果条数 |
| 新文件稳定等待 | 1500 ms | 等待复制或下载写入趋于稳定 |
| 文件删除时自动移除 | 开 | 磁盘文件删除后同步清理记录 |

切换全局采样模式不会立即重建已有索引，重建后才按新模式抽帧；单独指定模式的视频保留其选择。
两种模式都受预算限制，场景检测不保证覆盖全部镜头。原理见 [采样与抽帧](how-search-works.md#采样与抽帧)。

## 数据与备份

默认数据位于程序同级 `data`，macOS 取 `.app` 同级，Linux 取 AppImage 同级：

| 子目录 | 内容 |
| --- | --- |
| `db/` | SQLite 索引库及 WAL 附属文件 |
| `logs/` | 本地运行日志及轮转日志 |
| `frames/` | 开启保留索引帧后保存的帧图 |
| `session/` | WebView 缓存与界面偏好（macOS 除外） |

备份、迁移或覆盖程序前先退出应用，再复制整个 `data`，不要只复制正在使用的数据库文件。
程序目录不可写时启动失败，不自动回退到用户目录；可用 `WHICHVIDEO_DATA_DIR` 显式指定可写位置。

macOS 的 WKWebView 界面偏好保存在 `~/Library/WebKit/com.weiningwei.whichvideo/`，不随程序目录迁移。
升级保留数据不等于旧指纹仍然适用；当前统一缩放预处理需要重新索引旧视频，不提供旧滤镜兼容路径。

## 诊断信息

在「索引设置」中导出诊断 ZIP，并附复现步骤和视频格式。
诊断包包含版本、系统、媒体工具探测和索引状态等汇总，
不含日志、视频、缩略图、数据库、文件名或实际路径。
本地日志可能包含绝对路径，公开分享前请脱敏。更多处理方法见 [排障手册](troubleshooting.md)。
